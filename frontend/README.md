# Dashboard

Одностраничный аналитический dashboard для просмотра ключевых бизнес-показателей. На экране есть карточки метрик, график выручки и прибыли, а также блок рекомендаций.

## Что сделано

- Сверстан адаптивный dashboard в темной теме.
- Добавлены карточки: выручка, маржа, средний чек, количество чеков.
- Реализован линейный график за неделю.
- Добавлен блок рекомендаций.
- Проект настроен на Next.js App Router.

## Технологии

- Next.js 16
- TypeScript
- Tailwind CSS 4
- Recharts
- Lucide React

## Запуск

```sh
npm install
npm run dev
```

Приложение запускается на `http://localhost:3000`.
